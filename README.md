## Цель проекта

Разработать программно-аппаратный комплекс на базе Raspberry Pi 5, камеры и манипулятора, который играет с человеком партию в шахматы.

## Задачи проекта

1. Подготовить рабочую зону: доска, фигуры, крепление камеры над доской, зона для снятых фигур, захват.
2. Найти доску на кадре по ArUco-меткам в углах, построить гомографию и получить 64 клетки в координатах изображения. Определять положение фигур на клетках.
3. Сравнить позиции до и псоле хода и подтверждать результат через список легальных ходов в 'python-chess'. Обработать взятие, рокировку, взятие на проходе и превращение пешки.
4. Подключить Stockfish через UCI(Universal Chess Interface), настроить уровни сложности и время на ход.
5. Связать координаты клеток на изображении с координатами манипулятора и проверить точность позиционирования над центром клетки.
6. Реализовать операции «взять фигуру» и «поставить фигуру» с учётом высоты разных фигур, плавные траектории и безопасную высоту переноса. Отдельно реализовать взятие и рокировку.
7. Связать компоненты в цикл «ожидание хода → распознование → проверка → расчёт → исполнение → ожидание». Предусмотреть обработку ошибок: нелегальный ход, неуверенное распознование, промах захвата, повторный запрос подтвреждения.
8. Ограничить движение манипулятора, пока рука человека в кадре над доской. Добавить аварийную остановку.
9. Сделать интерфейс с текущей позицией и статусом робота, написать инструкцию запуска и описание архитектуры, подготовить демонстрацию.
